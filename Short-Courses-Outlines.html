Computer Skills Short Courses

Four 30-hour practical courses — Computer Literacy, Python Programming, Java Programming and Web Development. Delivered in daily one-hour sessions over six weeks, each closing with a hands-on final project.
1 · Computer Literacy 2 · Python Programming 3 · Java Programming 4 · Web Development

01Computer Literacy30 hours

Course goal: Build practical computer skills needed for study, work, communication, file management, productivity and basic digital problem-solving.

WeekTopicsPractical Activities
Week 1Computer FundamentalsComputer hardware, input/output devices, operating systems, keyboard and mouse skills, desktop navigation
Week 2Windows & File ManagementCreate, rename, copy, move and delete files; folders; file extensions; storage devices; downloads; basic troubleshooting
Week 3Microsoft WordCreating documents, formatting text, paragraphs, tables, images, page layout, headers/footers, saving and printing
Week 4Microsoft ExcelWorksheets, cells, formatting, basic formulas, SUM, AVERAGE, MIN/MAX, sorting, filtering and simple charts
Week 5Internet, Email & Digital CommunicationWeb browsers, search techniques, email, attachments, downloads, cloud storage and online communication
Week 6Digital Safety & ProductivityPasswords, phishing, malware, privacy, backups, responsible internet use, troubleshooting and productivity tools
Final ProjectDigital Office ChallengeCreate a professional Word document, Excel spreadsheet, organize files into folders and send an email with attachments

Daily 1-Hour Structure

  • 10 minReview / recap
  • 15 minInstructor demonstration
  • 25 minHands-on practical
  • 10 minExercise / assessment

02Python Programming30 hours

Course goal: Introduce learners to programming concepts and Python, developing their ability to solve problems and create simple working applications.

WeekTopicsPractical Activities
Week 1Introduction to Programming & PythonWhat is programming? Algorithms, pseudocode, Python environment, variables, data types, input and output
Week 2Operators & Decision MakingArithmetic, comparison and logical operators; if, elif and else; practical decision-making programs
Week 3Loops & Data Structuresfor loops, while loops, lists, tuples and dictionaries; processing collections of information
Week 4Functions & Modular ProgrammingCreating functions, parameters, return values, reusable code and problem decomposition
Week 5Files, Errors & DebuggingReading and writing files, exceptions, error handling, modules and debugging techniques
Week 6Python Application ProjectProject planning, coding, testing, debugging and presentation of a complete Python application
Final ProjectPython ApplicationBuild a practical application such as a quiz, student marks system, calculator or simple inventory system

Daily 1-Hour Structure

  • 10 minReview / programming concept
  • 15 minInstructor coding demonstration
  • 25 minLearner coding exercise
  • 10 minDebugging / review

03Java Programming30 hours

Course goal: Introduce learners to Java programming, beginning with fundamental programming concepts and progressing into object-oriented programming.

WeekTopicsPractical Activities
Week 1Introduction to JavaWhat is Java? JDK and IDE, Java program structure, variables, data types, input and output
Week 2Operators & Decision MakingArithmetic, comparison and logical operators; if, else, nested conditions and switch
Week 3Loops & Arraysfor, while, do-while, arrays and processing multiple values
Week 4Methods, Classes & ObjectsMethods, parameters, return values, classes, objects and constructors
Week 5Object-Oriented ProgrammingEncapsulation, inheritance, polymorphism and basic object-oriented design
Week 6Java Application ProjectProject planning, development, testing, debugging and presentation
Final ProjectJava ApplicationBuild a practical application such as a student management, library or employee management system

Daily 1-Hour Structure

  • 10 minReview / programming concept
  • 15 minInstructor coding demonstration
  • 25 minLearner coding exercise
  • 10 minDebugging / review

04Web Development30 hours

Course goal: Introduce learners to the fundamentals of web development and enable them to design and build a responsive, interactive website.

WeekTopicsPractical Activities
Week 1Introduction to Web Development & HTMLHow websites work, browsers, servers, HTML structure, headings, paragraphs, links, images and lists
Week 2HTML & Web Page StructureTables, forms, navigation, semantic HTML, page structure and multi-page websites
Week 3CSS & Web DesignColours, fonts, spacing, borders, backgrounds, selectors, classes and page layouts
Week 4CSS Layout & Responsive DesignFlexbox, Grid, responsive design, mobile-friendly layouts and website styling
Week 5JavaScript FundamentalsVariables, data types, operators, conditions, functions, events and basic DOM manipulation
Week 6Interactive Website ProjectWebsite planning, development, testing, debugging, responsive design and presentation
Final ProjectPersonal / Business WebsiteBuild a 3–4-page responsive website containing Home, About, Services/Projects and Contact pages

Daily 1-Hour Structure

  • 10 minReview / web concept
  • 15 minInstructor demonstration
  • 30 minWebsite development
  • 5 minReview / save work
